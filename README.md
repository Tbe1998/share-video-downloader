# 抖音无水印下载器（桌面版 v2.0）

一个 Windows 桌面小工具：粘贴抖音分享链接 → 解析 → 选清晰度 → 下载无水印 mp4。

![界面](docs/screenshot.png)

## 为什么重写

旧的纯 HTTP 解析（`douyin_dl.py`）已经失效：抖音现在对分享页和 `aweme/detail` 接口都加了
**a_bogus / x-secsdk-web-signature 签名 + 风控**，纯脚本请求一律 403；yt-dlp 现在也报
`Fresh cookies are needed`。

新方案让**本机已经装好的 Edge / Chrome 自己去发那条合法请求**（浏览器会完成签名），
程序通过 DevTools 协议把结果取出来，再直连 CDN 下载：

```
启动本机 Edge/Chrome（独立 profile，可复用登录态）
   └─ 打开 https://www.douyin.com/video/{id}
        ├─ 页面自己发出带签名的 aweme/detail 请求  ──┐
        │                                            │
        └─ 程序从 performance 里取出这条"已签名 URL" ─┘
                └─ 在页面内 fetch 重放 → 拿到全部码率列表（含 1080P/4K）
                        └─ 选档 → 直连 douyinvod CDN 下载无水印 mp4
```

如果重放拿不到数据（未登录 / 被风控），自动降级为**页面播放流兜底**：从页面已加载的
媒体流里挑码率最高的一条下载，一般得到 720P 无水印。

## 用法

1. 双击 `抖音视频下载器.exe`（或 `python app.py`）。
2. 把抖音分享链接粘到输入框——**可以直接粘整段分享文字**（如「9.43 复制打开抖音… https://v.douyin.com/xxxx/ …」），
   程序会先跟随短链跳转解析出作品 ID，再解析作品。
3. 选清晰度，点 **下载**。完成后可 **播放** / **打开所在文件夹**。
4. 保存位置默认是「下载」文件夹，选过的目录会进「历史目录…」下拉。
5. 右上角常驻 **登录状态**（启动时自动检测，也可点『检查登录』重查）：
   `已登录（昵称）` 为绿色，`未登录` 为橙色。

遇到「解析失败 / 被风控 / 只有 720P」：点 **登录抖音**，在弹出的浏览器窗口里扫码登录，
登录后**不用关窗口**，直接点『检查登录』确认变成绿色即可（登录状态存在独立浏览器 profile 里，长期有效）。

## 命令行（可选）

```bat
抖音视频下载器.exe --cli "https://v.douyin.com/xxxxxxx/" -q 1080p -o D:\视频
抖音视频下载器.exe --status      :: 只看登录状态
抖音视频下载器.exe --selftest    :: 运行库自检（不联网）
```

## 自己打包 exe

双击 **`一键打包exe.bat`**（需本机装有 Python 3.10+，安装时勾选 Add to PATH）。
脚本会自动装 PySide6 + PyInstaller 并产出 `抖音视频下载器.exe`（约 80–150MB，双击即用，
目标机器不需要装 Python）。

容器/CI 里打包见 `.github/workflows/build-exe.yml`。

## 已知限制（如实说明）

- **只能在 Windows/有桌面环境的机器上跑**：它要启动一个真实浏览器。
- 免登录时通常只能拿 720P（页面播放流）；1080P/4K 需要登录态，或重放 detail 接口成功。
- 抖音随时会改风控；改到连浏览器都不给数据时，需要更新本工具的取数逻辑。
- 只支持视频作品，**图文/图集作品不支持**。
- 下载失败常见原因：作品已删/私密、链接不是作品链接、网络不通。

## 手机网页版（v2.7 起）

电脑上点 **手机网页版** → 弹窗里有**二维码**和地址 → 手机连同一个 WiFi 扫码即可用。
也可以无界面常驻：`抖音视频下载器.exe --web 8990 --out D:\视频`（打印出地址，手机浏览器打开）。

- 解析、下载都在**这台电脑**上跑，用的是电脑的浏览器和抖音登录态（所以 4K/1080P 一样能拿）。
- 手机上能做：粘贴/解析、看封面标题时长、选清晰度、下载、进度、**保存到手机**、在手机里播放、
  **让电脑弹出登录窗口**（手机扫码）、刷新登录状态。
- 改端口/固定端口：`%APPDATA%\DouyinDownloader\config.json` 里 `"web_port": 8990`。
- 地址里带一个随机口令 `?k=xxxxxx`，同网段但没有这个口令的设备调不动接口。
- 电脑端独占的：诊断、检查更新、打开目录——这些在电脑上做。

## 自动更新（v2.5 起；v2.8 起换了可靠的安装方式）

**v2.8 之前点更新会卡住**：替换脚本用 `tasklist | findstr <PID>` 等自己退出，PID 会误匹配到别的进程，
循环退不出来（表现为弹一个黑色 cmd 窗口一直没动静）。v2.8 起改成：

1. 新版本下载到 `%TEMP%\DouyinDownloader-new-v<版本>.exe`（不写进安装目录）
2. 旧程序启动这个**新 exe**，带上参数：`--install-update --old-exe "<旧路径>" --old-pid <PID>`
3. 新 exe（Python 实现，不开 cmd 窗口）等旧进程退出 → 备份旧程序为 `.exe.bak` → 覆盖 → 启动新版
4. 全过程写日志：`%APPDATA%\DouyinDownloader\update.log`，失败会弹窗说明原因并保留原程序可用

旧版的 `.cmd` 只作为兜底（加了循环次数上限，不会死等）。

国内直连 GitHub 经常失败，所以更新走**多源**，按顺序自动尝试：

1. `http://192.168.1.6/download/douyin/latest.json` —— **家里局域网的 NAS 镜像**（最快，几毫秒）
2. `https://www.topbei.cn/download/douyin/latest.json` —— 公网 HTTPS 镜像（不在家也能用）
3. `https://api.github.com/…/releases/latest` —— 直连 GitHub（可能被墙，最后兜底）

下载 exe 时若某个源失败，会自动换下一个；GitHub 资产还会额外尝试
`ghfast.top` / `gh-proxy.com` / `ghproxy.net` 三个加速镜像。下载完**必须 sha256 校验通过**才替换。

想换源：编辑 `%APPDATA%\DouyinDownloader\config.json` 里的
`"update_manifest": "http://你的地址/latest.json,https://备用/latest.json"`（逗号分隔，留空=默认）。

- 启动时**静默检查**一次；有新版本会在日志和底部提示条里写出来（含更新源）。
- 点右上角 **检查更新** → 有新版弹窗显示更新说明 →「是」→ 自动下载校验 → 关闭 →
  替换 exe → **自动重新打开新版本**。
- 登录状态、保存目录、设置都在 `%APPDATA%\DouyinDownloader`，更新 exe 不影响。
- 每次发布同时提供两种形态：
  - `DouyinDownloader.exe`：**应用内更新用的单文件**
  - `抖音视频下载器-vX.Y.zip`：完整文件夹（exe + 使用说明 + 版本信息）

## 解析方式失效时

连续解析失败 2 次，程序会明确提示"解析方式可能已经失效"，并给出两步建议：
① 先点 **检查更新**；② 仍失败就点 **复制诊断信息**（版本、系统、最近错误、最近 40 行日志），
把内容发给助手。助手修好后发新 release，你这边点一次 **检查更新** 就升级完毕。

## 遇到问题

| 现象 | 处理 |
|---|---|
| **浏览器启动超时 / 浏览器启动后立刻退出** | v2.3 起会自动接管上次没关干净的浏览器、并结束残留进程后重试；超时时间也从 25s 放宽到 45s。若仍失败：关掉所有 Edge/Chrome 窗口后重试，或点右上角 **诊断** 把检查结果发我 |
| 解析失败 / 只有「页面流」 | 点 **登录抖音** 扫码登录，登录后点 **检查登录** 确认变绿色再解析 |
| 界面没有样式 / 排版乱 | v2.2 已修（Qt 样式表不支持 `:not()` 会拖垮整张表） |
| 杀毒软件报未知发布者 | 单文件 exe 未签名，SmartScreen 点「更多信息 → 仍要运行」 |

点 **诊断** 会把这些写进日志：系统与 Python 版本、浏览器路径与版本、配置目录是否可写、
上次浏览器记录的端口/PID/是否存活、端口可用性、启动耗时、登录状态。

## 文件说明

| 文件 | 作用 |
|---|---|
| `app.py` | 主程序：PySide6 图形界面 + 命令行模式 |
| `engine.py` | 浏览器引擎：启动 Edge/Chrome、取签名请求、解析码率、下载 |
| `cdp.py` | 极简 Chrome DevTools Protocol 客户端（纯标准库 WebSocket，无第三方依赖） |
| `dycore.py` | 公共小工具（文件名清洗、体积格式化、旧版纯 HTTP 解析备查） |
| `_gui_smoke.py` | 自动化冒烟测试（离屏跑完整解析+下载并截图） |
| `一键打包exe.bat` | 一键打成单文件 exe |
